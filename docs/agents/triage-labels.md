# Triage labels

Use these canonical labels when triaging GitHub issues. Preserve their names and meanings so automation and agents can rely on them.

| Label | Meaning |
| --- | --- |
| `needs-triage` | Newly reported work that needs initial classification. |
| `needs-info` | Work cannot proceed until the reporter or owner provides information. |
| `ready-for-agent` | Scope and acceptance criteria are clear enough for an agent to implement. |
| `ready-for-human` | Needs a human decision, approval, or action before it can proceed. |
| `wontfix` | Intentionally not planned for implementation. |

Apply the smallest set of labels needed to communicate the issue's current state. Remove superseded state labels when the issue advances.
